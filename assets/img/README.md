# assets/img

`logo.svg` — Mado logo (violet; lighter violet in dark mode).
`logo-purple.svg`, `logo-white.svg`, `logo-black.svg` — fixed colours.
`logo-512.png`, `logo-192.png`, `logo-180.png`, `favicon.ico` — raster versions.

`nostrich.png` — default avatar (256 × 256, round).

**Purple Nostrich Icon** by SovrynMatt — <https://github.com/SovrynMatt/Nostr-Website-Button-Design>. Free and open source, as stated by its author. See `CREDITS.md`.

To use another default avatar, set `site.fallbackAvatar` in `config.json` (or in the settings page) instead of replacing this file.
